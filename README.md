# 🛡️ ThreatSentinel

> The first onchain URL threat detector. No server. No bias. No tampering.

## What is it?
ThreatSentinel is a blockchain-powered URL security scanner. Paste any link and multiple AI validators reach consensus on whether the site is **safe**, **phishing**, or **malicious** — verdict recorded onchain forever on GenLayer.

## Live Demo
🔗 [threatsentinel.vercel.app](https://threatsentinel.vercel.app)

## How it works
1. User pastes a URL
2. Intelligent Contract fetches the live page HTML
3. Multiple AI validators independently analyze it
4. Validators reach consensus via Optimistic Democracy
5. Verdict is written onchain permanently

## Tech Stack
- **Frontend** — Next.js, Tailwind CSS, RainbowKit
- **Blockchain** — GenLayer Studionet
- **AI** — LLM consensus via GenLayer validators
- **Wallet** — MetaMask / any Web3 wallet
